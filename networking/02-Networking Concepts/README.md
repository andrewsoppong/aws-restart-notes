# Types of Networks

| Network Type | Description |
|---|---|
| LAN | Local Area Network used within a small geographic area |
| WLAN | Wireless Local Area Network using Wi-Fi |
| WAN | Wide Area Network connecting networks over large distances |
| MAN | Metropolitan Area Network covering a city or campus |

---

# Network Topologies

| Topology | Description |
|---|---|
| Bus | Devices connected to a single cable |
| Star | Devices connected through a central switch/router |
| Ring | Devices connected in a circular pattern |
| Mesh | Devices interconnected with multiple paths |

---

# Network Management Models

## Client-Server Model
- Centralized management
- Servers provide resources/services
- Clients request resources

## Peer-to-Peer Model
- Devices share resources directly
- No centralized server
- Simpler but less scalable

---

# Network Protocols

| Protocol | Purpose |
|---|---|
| TCP/IP | Communication across networks |
| HTTP/HTTPS | Web communication |
| DNS | Converts domain names to IP addresses |
| FTP | File transfer |
| SSH | Secure remote access |

---

# Amazon Virtual Private Cloud (VPC)

Amazon VPC is a logically isolated virtual network in AWS where cloud resources can be launched securely.

## Features of Amazon VPC
- Isolated AWS network
- Custom IP ranges
- Public and private subnets
- Route tables
- Security groups

---

# Comparing LAN/WLAN and Amazon VPC

| Feature | LAN/WLAN | Amazon VPC |
|---|---|---|
| Location | Physical environment | Cloud environment |
| Infrastructure | Physical hardware | Virtual AWS infrastructure |
| Connectivity | Local network/Wi-Fi | AWS cloud networking |
| Scalability | Limited | Highly scalable |
