# Key Networking Terms

| Term | Meaning |
|---|---|
| Network | A group of connected computers/devices |
| Internet | A global network connecting millions of devices |
| IP Address | Unique address assigned to a device |
| Router | Device that forwards traffic between networks |
| Switch | Connects devices within a network |
| Server | Provides services/resources to clients |
| Client | Device requesting services |

# File Permissions in Linux

## Symbolic Permissions

| Symbol | Meaning |
|---|---|
| r | Read |
| w | Write |
| x | Execute |

Example:
```bash
rwxr-xr--
```

---

## Absolute (Numeric) Permissions

| Number | Permission |
|---|---|
| 7 | rwx |
| 6 | rw- |
| 5 | r-x |
| 4 | r-- |

Example:
```bash
chmod 755 filename
```
