# Introduction to Python Modules

A module in Python is a file that contains reusable Python code such as functions, variables, and classes.

Modules help programmers:

- Organize code
- Reuse code efficiently
- Simplify large programs
- Share functionality across projects

Example:

```python
import math

print(math.sqrt(25))
